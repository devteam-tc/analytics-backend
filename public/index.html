📊 Analytics Backend API

A Node.js Express server providing Google Analytics data through REST API endpoints.

Available Endpoints

GET
/health
Health Check

Check if the API is running properly.

Response: JSON with status and timestamp

GET
/api/analytics?period=day|week|month
Analytics Data

Get Google Analytics data for the specified time period.

Parameters:

  • period - Time period: day, week, or month

Response: Array of analytics data with dates and user counts

Example Usage

# Health check
curl https://your-project-id.web.app/health

# Get analytics for the last week
curl https://your-project-id.web.app/api/analytics?period=week

# Get analytics for the last month
curl https://your-project-id.web.app/api/analytics?period=month

Response Format

[
  {
    "date": "20231201",
    "users": "123"
  },
  {
    "date": "20231202", 
    "users": "145"
  }
]

Deployed on Firebase Cloud Functions
